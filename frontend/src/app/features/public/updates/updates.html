Product Changelog

What's New in School Linx.

We ship meaningful improvements every week. Follow along to see exactly how the platform is evolving to serve you better.

v2.8 — August 2026 Latest Major Release
Security, Audit & Compliance Centre

Super Admins can now enforce 2FA per-tenant, track every platform action in an immutable audit log, and manage IP whitelists for additional security layers. DPA compliance status is displayed per school.

System Health Dashboard

New DevOps control centre with real-time API health matrix, service degradation alerts, and a centralized support ticket inbox for schools to reach the admin team directly.

Telemetry & Usage Analytics

Platform-wide telemetry now tracks login patterns, feature usage heatmaps, and error rates per tenant. Exportable as CSV from the Super Admin portal.

v2.7 — July 2026 Feature Release
Affiliate & Reseller Management

New affiliate portal tracks reseller links, conversion metrics, and commission payouts. Payout processing via Paystack is fully automated.

Global Analytics Dashboard

Cross-tenant analytics with geographic distribution maps, growth cohort analysis, and platform-wide revenue KPIs are now live for Super Admins.

v2.6 — June 2026 Improvement
Tenant Lifecycle Management

Full tenant onboarding, suspension, and offboarding workflow with automated schema provisioning. Subscription plan management and per-student billing are now live.

SMS Credit Ledger

Granular SMS credit tracking with full transaction history per school. Super Admins can inject credits, view consumption trends, and set usage alerts.
